# Sales Performance Analysis

## Project Overview

This project analyzes retail sales data to identify business trends, profitable categories, top-performing products, and regional performance.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Data Cleaning
- Missing Values Check
- Duplicate Records Check
- Exploratory Data Analysis (EDA)
- Sales Analysis
- Profit Analysis
- Product Performance Analysis
- Regional Analysis
- Data Visualization

## Key Insights

- Identified top-performing categories based on sales.
- Compared profitability across business categories.
- Analyzed regional sales distribution.
- Discovered best-selling products.

## Business Recommendations

- Focus marketing efforts on profitable categories.
- Optimize inventory for high-demand products.
- Review low-profit products and discount strategies.
